# 📚 Library Book Inventory Manager

A simple and efficient Python-based Library Inventory Management System built using Object-Oriented Programming (OOP) principles and JSON for persistent data storage.

## ✨ Features
- **Add Books:** Add new books with unique IDs, titles, and authors.
- **Fast Lookup:** Uses Python dictionaries (HashMap concept) for $O(1)$ fast searching.
- **Search Functionality:** Search books easily by title or author name.
- **Issue & Return:** Track book status (Available / Issued) in real time.
- **JSON Data Persistence:** Automatically saves and reloads book data from `books.json`.
- **Inventory Reports:** Generate quick summary reports showing total, issued, and available books.

## 🛠️ Tech Stack
- **Language:** Python 3
- **Data Format:** JSON
- **IDE:** Visual Studio Code
